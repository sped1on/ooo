# Дорога Зомби

3D-игра для **Яндекс Игр** (телефон и ПК): собираешь и прокачиваешь машину в гараже, выезжаешь с базы
и едешь к следующей через земли, полные зомби. По пути собираешь ресурсы, чинишь машину, отстреливаешься,
а на заправке посередине маршрута выходишь из машины и заправляешься, отбиваясь от толпы.

Графика — лёгкая low-poly с детализацией: процедурные текстуры профнастила, досок, кирпича и бетона,
полый салон машин, интерьер гаража. Все модели (машины, оружие, зомби, постройки, природа) собираются из примитивов
в коде, текстуры рисуются на canvas, звуки и музыка синтезируются WebAudio. Внешних картинок и звуков нет.

## Что есть в игре

- **Главное меню** с 3D-сценой базы, профилем игрока, уровнем и опытом, карточкой базы (улучшения базы за ресурсы).
- **Гараж**: машину можно вращать мышью или пальцем (два пальца или колесо — приближение). 11 машин и детали на поворотном круге — оружие на крышу, бронелисты (двери, капот, полная обшивка, шипы), бампера, решётки, окраска, диски.
  Категория «Салон» показывает кабину изнутри: 5 рулей, подвески на зеркало (ёлочки, кубики, чётки), фигурки на панель (уточка, собачка-кивалка, кактус, череп) — они качаются в поездке.
  **Баллончик**: рисуй прямо по машине (12 цветов, 3 размера пятна); краска расходуется, баллончики покупаются. Рисунок хранится для каждой машины.
  Характеристики «Прочность / Скорость / Урон / Таран / Багажник» с подсветкой разницы. Ремонт за ресурсы, деньги или рекламу.
- **Магазин** (машины и детали): Авто, Оружие (15 видов на машину), Бампера, Решётки, Краска, Диски, Предметы.
  Новые машины открываются на следующих базах.
- **Снаряжение**: ручное оружие (19 видов по категориям и редкости, улучшения урона/скорострельности/магазина),
  броня (жилеты и шлемы), аптечки, расходники.
- **Карта уровня** перед поездкой: 3D-обзор маршрута с метками (базы, ресурсы, зомби, мост, заправка, лагерь бандитов),
  схема маршрута и легенда.
- **Поездка**: вид из кабины (салон с сиденьями, приборка, руль и руки) или камера сзади. Зомби восьми видов:
  ходоки, бегуны, ползуны, громилы, бронированные (пули почти не берут), плевуны кислотой, взрывные и бандиты.
  Зомби охотятся на игрока: выходят на полосу, цепляются за машину сбоку (их стряхивают, виляя рулём).
  С каждой базой они сильнее, быстрее и разнообразнее. Перед каждой базой — босс (Танк таранит, Королева заразы
  плюётся и призывает бегунов, Мясник в броне); с 5-й базы Мясник приходит и на заправку.
  Также: бандиты со стрельбой, турель, мины и шипы на дороге, взрывающиеся бочки, ящики с добычей, мост через озеро.
  Ресурсы (дерево, металл, ткань, патроны) ограничены багажником. Топливо расходуется — на заправке в середине пути
  нужно выйти из машины и (от первого лица) дойти до колонки. Оружие стреляет само, когда зомби в прицеле,
  а прицел слегка притягивается к ближайшей цели.
- **10 уникальных поездок** (к базам 2–11): день, закат, рассвет, пасмурно, ночь с фонарями и фарами; дождь, гроза с молниями,
  снегопад со скользкой дорогой, туман; долины, холмы, степь, горный серпантин, красный каньон. Трамплины (прыжок над кучей
  машин, дуга из монет, бонус за прыжок) и развилки с указателем: одна ветка ведёт к базе, другая — к орде и минам.
  У каждой базы свой вид ограды (металл, частокол, бетон, хаки), у заправок — свои цвета. Дальше 11-й базы — сочетания вариантов.
- **Аркада**: бесконечная кольцевая трасса (5 карт), считаются километры. Канистры, ремкомплекты и патроны на дороге,
  трамплины, орды; каждые 700 м угроза растёт, каждые 2 км — босс. Рекорд, свои лучшие заезды и таблица лидеров `arcade`.
- **Кат-сцены**: выезд из гаража через ворота; въезд на новую базу → чёрный экран с печатающимся названием
  «БАЗА 2» и звуком машинки → проявляется машина в гараже с итогами поездки.
- **Награды**: 7 ежедневных призов, рулетка (бесплатно раз в сутки, дополнительно за рекламу), реклама за деньги.
- **Задания**: 24 цели с наградами (в том числе прыжки и аркада).
- **Настройки**: звук, музыка, качество графики, камера, автострельба, тряска, сброс прогресса.

## Управление

| | ПК | Телефон |
|---|---|---|
| Руль | `A`/`D` или стрелки | кнопки ◀ ▶ |
| Газ / тормоз | `W` / `S` | тормоз — кнопка |
| Огонь | `Пробел` или ЛКМ (прицел автоматический) | кнопка прицела |
| Ремкомплект / канистра | `R` / `F` | кнопки |
| Дрифт | `C` или `Shift` (удерживать в повороте) | кнопка дрифта |
| Камера | `V` | кнопка |
| Пешком (от первого лица) | `WASD`, мышь — обзор (клик захватывает мышь), стрелки — поворот, стрельба сама; `H` — аптечка, `E` — сесть в машину | джойстик слева, обзор — палец по правой половине экрана |
| Пауза | `Esc` | кнопка ⏸ |

## Запуск и сборка

```bash
cd zombie
npm install
npm start          # http://localhost:8090 — версия для разработки
npm run build      # dist/zombie-road-yandex.zip — архив для консоли Яндекс Игр
npm run preview    # http://localhost:8091 — проверить собранную версию
```

Архив `dist/zombie-road-yandex.zip` загружается в консоль разработчика Яндекс Игр (index.html лежит в корне архива).

## Яндекс Игры

Интеграция — в `js/platform/yandex.js`:

- SDK подключается из `/sdk.js`, `LoadingAPI.ready()` вызывается, когда меню отрисовано;
- `GameplayAPI.start/stop` — во время поездки и на паузе;
- полноэкранная реклама — перед выездом и после итогов поездки (не чаще раза в 90 секунд);
- реклама за вознаграждение: деньги, ×2 награда за базу, продолжение после поражения, бесплатный ремонт,
  вращение рулетки, ресурсы для базы;
- на время рекламы и при сворачивании вкладки звук выключается, поездка ставится на паузу;
- прогресс хранится в облаке (`player.setData`) и в localStorage;
- покупки золота: заведите в консоли товары `gold100`, `gold300`, `gold1000` — окно «Купить валюту» покажет их сам;
  без них остаётся обмен золота на деньги и реклама;
- таблицы лидеров (создайте в консоли): `bases` — номер достигнутой базы, `arcade` — рекорд аркады в метрах
  (тип «число», сортировка по убыванию); экран аркады показывает топ-10 и место игрока.

В консоли рекомендуется указать горизонтальную ориентацию для телефонов; портретная тоже поддерживается
(меню перестраивается, в поездке включается камера сзади).

Вне Яндекса вместо рекламы показывается короткая заглушка «Реклама (демо)», чтобы игру можно было проверить.

## Названия

Машины и оружие в игре названы вымышленными именами (Семёрка «Классик», Шмель «Турбо», Пикап «Бизон» и т.д.), без реальных марок и логотипов:
реальные марки автомобилей — товарные знаки, и модерация Яндекс Игр может отклонить игру с ними.
Названия меняются в одном месте — `js/data/catalog.js`.

## Структура

| Путь | Что внутри |
|---|---|
| `js/data/catalog.js` | машины, детали, оружие, снаряжение, базы и биомы, задания, награды, рулетка |
| `js/state/save.js` | сохранение, характеристики машины и оружия |
| `js/world/cars.js` | модели машин из профилей, бампера, решётки, диски, 15 видов оружия на крышу, кабина с руками |
| `js/world/props.js` | природа, постройки, заправка, лагерь бандитов, мост, база |
| `js/world/characters.js` | зомби и бандиты (InstancedMesh), модель игрока с бронёй |
| `js/world/guns.js` | ручное оружие, броня, аптечки |
| `js/world/track.js` | дорога, рельеф (долина, холмы, горы, каньон), развилки, трамплины, озеро; кольцо для аркады |
| `js/world/env.js` | небо (звёзды ночью), горы, свет, время суток, дождь и снег |
| `js/state/spray.js` | рисунки баллончиком (слой поверх краски) |
| `js/ui/arcade.js` | экран аркады, итоги заезда, таблица лидеров |
| `js/world/level-world.js` | наполнение уровня и точки маршрута |
| `js/world/scenes.js` | сцены меню (база снаружи) и гаража |
| `js/game/level.js` | игровая логика поездки, заправки пешком и кат-сцен |
| `js/engine/` | частицы, звук, текстуры, построитель геометрии |
| `js/ui/` | экраны: меню, гараж, магазины, награды, задания, настройки, карта, HUD |
| `scripts/build.mjs` | сборка архива для Яндекс Игр |

# Коридор · Шахматы · Шашки

Три 2.5D-настольные игры в одном приложении для **Яндекс Игр**: Коридор (Quoridor), шахматы и русские шашки.
Игра переключается в меню — меняются название, правила, превью и магазин.

- **Шахматы:** полные правила (рокировка, взятие на проходе, превращение, мат/пат/ничьи), бот 3 уровней.
- **Шашки:** русские правила — обязательное бить, цепочки взятий, летающие дамки.
- **Упражнения:** по 5000 уровней в каждой игре на ступенях «Новичок» (уроки с объяснениями) и «Умею играть» (задачи на логику).
- **Ежедневная рулетка:** бесплатное вращение раз в день, дополнительные — за рекламу; призы — монеты и скины.

## Что есть в игре

- **3D-поле (Three.js):** светящиеся финишные линии, тени, прыжки фишек, падающие стены, салют при победе.
- **Режимы:**
  - против бота (лёгкий, средний, сложный);
  - онлайн со случайным соперником (быстрый поиск);
  - с другом по ссылке или коду комнаты;
  - с другом на одном устройстве (поле можно поворачивать к тому, чей ход).
- **Время на ход:** 1, 3, 5 или 10 минут. Если время вышло, фишка сама делает шаг по кратчайшему пути.
- **Размер поля:** 5×5, 7×7, 9×9 или 11×11.
- **Магазин скинов:** 16 видов стен, 12 полей и 8 фишек. Все текстуры рисуются процедурно, превью в магазине — настоящие 3D-рендеры.
- **Монеты** начисляются за победы. Кнопка «+» на Яндексе показывает рекламу за 50 монет, вне Яндекса даёт ежедневный бонус.
- **Также:** правила с примером поля, настройки (звук, подсказки, анимации, наклон камеры, имя) и статистика.
- **Управление:** мышь, клавиатура (`Пробел` — фишка/стена, `R`/колесо/ПКМ — повернуть стену, `Ctrl+Z` — отмена) и касания (двойное касание ставит стену).

## Яндекс Игры

Интеграция находится в `public/js/platform/yandex.js`:

- SDK подключается из `/sdk.js` (на хостинге Яндекса), `LoadingAPI.ready()` вызывается после загрузки;
- `GameplayAPI.start/stop` отмечает начало и конец партий;
- полноэкранная реклама показывается между партиями (по кнопке «Ещё раз», не чаще раза в 90 секунд);
- реклама за вознаграждение: «+50 монет» и «x2 награды» после партии;
- на время рекламы и при сворачивании вкладки звук и таймер ставятся на паузу;
- прогресс хранится в облаке (`player.setData`) и дублируется в localStorage;
- лидерборд `wins` обновляется, если он создан в консоли;
- приглашение другу — ссылка `https://yandex.ru/games/app/<id>?payload=<код>`.

Сборка архива:

```bash
npm install
npm run build              # dist/koridor-yandex.zip
```

Архив `dist/koridor-yandex.zip` загружается в консоль разработчика Яндекс Игр.

### Онлайн на Яндексе

Для онлайн-режимов нужен свой сервер (`server/index.js`) с HTTPS/WSS. Его адрес вшивается при сборке:

```bash
ONLINE_URL=wss://your-server.example/ws npm run build
```

Без сервера режимы «Онлайн» и «По ссылке» показывают сообщение и предлагают сыграть с ботом. Бот и игра на одном устройстве работают полностью офлайн.

## Локальный запуск

```bash
npm install
npm start          # http://localhost:8080 — игра и онлайн-сервер
npm test           # правила, бот и сетевой протокол
```

## Структура

| Путь | Что внутри |
|---|---|
| `public/js/core/quoridor.js` | правила: ходы, прыжки, стены, проверка пути (общие для клиента и сервера) |
| `public/js/core/ai.js` | бот: минимакс с альфа-бета отсечением |
| `public/js/render/` | 3D-сцена, процедурные текстуры, материалы скинов, превью |
| `public/js/ui/` | экран партии, модальные окна, иконки |
| `public/js/data/skins.js` | каталог магазина |
| `public/js/state/store.js` | монеты, скины, настройки |
| `server/index.js` | статика + WebSocket: быстрый поиск, комнаты, таймеры, переподключение |
| `scripts/build.mjs` | сборка для Яндекс Игр и однофайловая версия |
